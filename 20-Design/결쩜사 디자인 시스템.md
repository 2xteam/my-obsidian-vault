# 결쩜사 디자인 시스템

실제 사이트에서 추출한 값이다. 새 페이지를 만들 때 이 토큰을 그대로 쓰면 결이 맞는다.
페이지 단위 구성은 [[결쩜사 페이지 패턴]], 문장 쓰는 법은 [[결쩜사 카피 톤앤매너]].

## 인상 한 줄

**보라(신비·정성) + 금(격식·귀함)** 을 밝은 오프화이트 위에 얹은, 동화책 같은 톤.
스펙 나열형 매칭 서비스와 다르다는 것을 색과 문장으로 먼저 말한다.

구조적으로는 **옅은 라벤더 배경 위에 둥근 시트를 쌓는 방식**이다.
전체 폭 섹션을 쓰지 않는 것이 이 사이트의 인상을 만드는 큰 축이다 → [[결쩜사 페이지 패턴]]

## 색 토큰

```css
/* 브랜드 보라 */
--ac:   #7C3AED;   /* 주 강조 — 버튼, 링크, 강조 텍스트 */
--ac2:  #A78BFA;   /* 보조 */
--ac3:  #C4B5FD;   /* 옅은 강조 */
--ac-bg: rgba(139,92,246,0.08);   /* 강조 배경 */
--ac-bd: rgba(139,92,246,0.22);   /* 강조 테두리 */

/* 금 — 격식·프리미엄 표현 (배지, 구분선, 씰) */
--gold:  #C9A84C;
--gold2: #E8C96A;
--gold-bg: rgba(201,168,76,0.1);
--gold-bd: rgba(201,168,76,0.3);

/* 배경 */
--bg:  #FDFBFF;    /* 페이지 기본 (거의 흰색인데 보라가 한 방울) */
--bg2: #F5F0FC;    /* 섹션 교차 배경 */
--bg3: #EDE6F8;    /* 더 진한 블록 */
--bg-dark:  #1E0938;  /* 다크 섹션 */
--bg-dark2: #2D1054;

/* 텍스트 */
--text:  #1A0F2E;  /* 본문 — 검정이 아니라 보라빛 먹색 */
--text2: #6B5F8A;  /* 보조 */
--text3: #786B9C;  /* 더 흐린 */

/* 테두리 */
--bd:  rgba(139,92,246,0.1);
--bd2: rgba(139,92,246,0.2);
```

**핵심**: 순수한 검정(`#000`)과 순수한 회색을 쓰지 않는다. 모든 중립색에 보라가 섞여 있다.
이것 하나만 지켜도 사이트가 같은 결로 보인다.

### 스토리/동화 계열 (긴 글·서사 섹션 전용)

```css
--story-ink: #1d102e;      --story-purple: #2a0b48;   --story-purple-2: #3a1760;
--story-violet: #8253e8;   --story-lilac: #bca7fb;
--story-gold: #c9a84c;     --story-gold-soft: #ead58c;
--story-paper: #fffdf8;    --story-paper-2: #faf6ee;   /* 종이 질감 */
--story-mist: #f6f1fb;     --story-rule: rgba(68,37,94,.12);
--story-shadow: 0 24px 65px rgba(37,13,62,.09);
--story-shadow-soft: 0 12px 34px rgba(37,13,62,.065);

/* 요정/동화 연출 */
--fairy-violet: #8b5cf6;  --fairy-lilac: #c8b8ff;
--fairy-gold: #e3bd4d;    --fairy-champagne: #fff2b6;  --fairy-ink: #21083f;
--fairy-ease: cubic-bezier(.16,1,.3,1);
```

그림자는 검정이 아니라 **보라 먹색을 낮은 투명도로** 깔아 공중에 뜬 느낌을 만든다.

## 타이포그래피

- 본문 서체: **Pretendard** (`pretendard.css` 자체 호스팅)
- 장식 서체: **Gowun Batang** (Google Fonts) — 서사·인용 등 감성 구간의 명조

> ⚠️ 서체를 시스템 스택으로 대체하면 색을 맞춰도 다른 사이트처럼 보인다.
> 우리 프로젝트에서 이 결을 따라갈 때는 Pretendard를 반드시 불러온다.
> `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard-dynamic-subset.min.css`

```css
--type-display: clamp(34px, 5vw, 66px);   /* 히어로 헤드라인 */
--type-section: clamp(24px, 3vw, 36px);   /* 섹션 제목 */
```

크기를 고정값으로 두지 않고 전부 `clamp()`로 잡는다. 모바일↔데스크톱 분기 없이 흐른다.

## 레이아웃

```css
--content-reading: 760px;   /* 글 읽는 폭 (노트·스토리) */
--content-wide: 1180px;     /* 카드·그리드 폭 */
--page-gutter: clamp(20px, 4.2vw, 64px);
--section-space: clamp(48px, 7vw, 96px);
--r:  14px;   /* 기본 모서리 */
--rs: 8px;    /* 작은 요소 */
```

읽기 폭과 넓은 폭 **두 가지만** 쓴다. 글은 760px, 카드 그리드는 1180px.

## 모션

```css
--motion-fast:  180ms;   /* 호버 등 즉각 반응 */
--motion-base:  260ms;   /* 일반 전환 */
--motion-brand: 720ms;   /* 브랜드 연출 (등장 애니메이션) */
--motion-ease:  cubic-bezier(.2,.72,.2,1);
```

- 스크롤 진입 시 `.motion-reveal` 클래스로 서서히 나타남
- `responsive-motion.js` / `responsive-motion.css`가 화면 크기·모션 선호도에 따라 강도를 조절
- 브랜드 연출(720ms)은 **히어로와 씰(seal) 같은 상징 요소에만** 쓴다. 남발하면 느려 보인다

## 컴포넌트 클래스 규칙

전역 클래스는 42개뿐이다. 접두사로 역할을 나눈다.

| 접두사 | 용도 | 예 |
|---|---|---|
| `ui-` | 버튼 등 범용 UI | `ui-btn-primary` `ui-btn-gold` `ui-btn-secondary` `ui-btn-muted` |
| `nav-` | 데스크톱 헤더 | `nav-links` `nav-apply-btn` |
| `mob-` | 모바일 메뉴 (15개) | `mob-menu` `mob-menu-head` `mob-nl` `mob-apply-btn` |
| `notif-` | 상단 알림 배너 | `notif-banner-inner` `notif-banner-close` |
| `kyul-` | 브랜드 상징 연출 | `kyul-moment` `kyul-moment-thread` `kyul-moment-seal` |
| `toast` | 알림 토스트 | `toast` `toast-dot` |

버튼은 **4종**으로 고정되어 있다: primary(보라) · gold(금) · secondary(외곽선) · muted(약함).
새 버튼 스타일을 추가하기 전에 이 4개로 표현 가능한지 먼저 본다.

## CSS·JS 파일 구성

정적 사이트(Next.js 아님). 역할별로 파일을 쪼개고 URL 쿼리로 캐시를 관리한다.

```
/static/css/style.css              공통 토큰·레이아웃·버튼
          home.css                 홈 전용
          home-signature.css       홈 시그니처 연출
          home-aurora.css          홈 배경 오로라
          subpage-aurora.css       서브페이지 배경
          fairytale.css            동화 연출
          romance-journey.css      스토리 여정 섹션
          responsive-motion.css    모션 강도 조절
          content-protection.css   콘텐츠 보호
          pretendard.css           서체

/static/js/ main.js  fairytale.js  home-signature.js
           page-density.js  responsive-motion.js  content-protection.js
```

**캐시 무효화**: `style.css?v=20260816-static-cache` 처럼 `?v=날짜-변경내용`을 붙인다.
파일명을 바꾸지 않고 버전만 올린다.

## 실측 수치 (로그인 화면 기준)

| 요소 | 값 |
|---|---|
| 카드 그림자 | `0 24px 65px rgba(37,13,62,.09)` |
| 큰 카드 radius | 24px |
| 입력 radius | 10px · 테두리 `rgba(72,42,97,.14)` · padding `11px 14px` |
| 버튼 | `linear-gradient(135deg,#8150E8,#6830C8)` · radius 11px · 그림자 `0 10px 24px rgba(104,48,200,.18)` |
| 탭(알약) | 감싸개 `#F6F1F9` radius 999px · 활성 흰색 + `0 4px 15px rgba(38,13,63,.08)` |
| eyebrow | 9~11px · 굵기 800~900 · `letter-spacing: 2px` |
| 폼 제목 | 22px · 700 · `letter-spacing: -0.65px` |

밝은 배경의 eyebrow는 보라, **어두운 배경의 eyebrow는 금색 `#EAD58C`**.

## 새 페이지를 만들 때 체크리스트

- [ ] 색은 위 토큰만 사용 — 새 색을 만들지 않는다
- [ ] 중립색에 보라가 섞여 있는지 (`#1A0F2E`, `#6B5F8A`)
- [ ] 폭은 760px(글) 또는 1180px(그리드) 중 하나
- [ ] 제목은 `clamp()` 기반 반응형
- [ ] 버튼은 4종 중 하나
- [ ] 섹션 등장은 `.motion-reveal`
- [ ] 금색은 강조점에만 (배지·구분선·씰) — 넓은 면적에 쓰지 않는다
- [ ] 페이지 하단 사업자 정보 블록 포함 ([[결쩜사 페이지 패턴]] 참고)
