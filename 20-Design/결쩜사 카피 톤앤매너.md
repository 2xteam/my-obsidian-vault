# 결쩜사 카피 톤앤매너

디자인보다 이 사이트를 더 강하게 규정하는 게 문장이다. 색만 맞추고 문장을 놓치면 다른 사이트가 된다.

## 어미 — `~해요체` 로 통일

전 페이지가 **해요체**다. `~합니다`(격식)도 `~한다`(단정)도 쓰지 않는다.

> 결쩜사는 조건표보다 사람의 리듬을 먼저 살펴봐요.
> 두 분이 모두 수락한 뒤에만 결제해요.
> 자세한 기준은 환불정책에서 확인할 수 있어요.

FAQ 답변, 주의사항, 환불 정책 같은 딱딱해지기 쉬운 구간에서도 해요체를 유지한다.
이게 이 브랜드의 온도다.

## 문장 리듬 — 짧게 끊고 줄바꿈으로 호흡

헤드라인은 줄바꿈 위치까지 설계 대상이다.

```
스펙보다
결(結)이
맞는 사람
```

```
조건으로 줄 세워지는 데
지쳤다면,
조금 다른 방식으로 만나보세요.
```

```
무료로 확인하고,
마음이 맞을 때만 결제해요
```

한 줄에 다 넣지 않는다. **끊는 자리에서 의미가 만들어진다.**

## 브랜드 어휘

| 표현 | 쓰임 |
|---|---|
| **결(結)** | 핵심 개념. 한자를 병기해 무게를 준다. "결이 맞는", "결 지표", "결(結) 기반 매칭" |
| **쩜미** | 운영자 페르소나. 회사가 아니라 사람이 한다는 인상 |
| 리듬 · 속도 · 온도 | 관계를 설명하는 은유. "대화의 속도", "연락의 리듬", "마음을 표현하는 온도" |
| 스펙 · 조건표 | 대비 대상. 부정하고 싶은 가치 |

**금지어에 가까운 것**: 조건, 등급, 스펙 우위, 성사율, 매칭 확률 같은 계량 표현.
숫자로 증명하지 않고 이야기로 증명한다.

## 신뢰를 만드는 방식

1. **불리한 조건을 먼저 말한다**
   > 연락처가 정상 제공된 뒤에는 답장 여부나 만남 성사 여부만으로는 환불이 어려워요.
2. **비교는 하되 실명을 쓰지 않는다** — "일부 선납형 서비스" + 각주로 방어
   > `* 업체·상품별 가격과 운영 방식은 다를 수 있습니다.`
3. **조건을 각주로 숨기지 않고 `NOTE` 블록으로 드러낸다**
   > `* 가입만으로는 카운트되지 않으며, 프로필 등록 완료가 필요해요.`
4. **후기는 별점이 아니라 서사** — 이니셜 + 직업으로만 노출

## 영문 라벨 사용법

국문 헤드라인 위에 영문 대문자 라벨(eyebrow)을 얹는다.
장식이지만 규칙이 있다: **짧고, 명사형이고, 그 블록의 성격을 한 단어로 말한다.**

```
PRICING · HOW IT WORKS · SAMPLE PREVIEW · FRIEND REFERRAL
EVENT FORMULA · HOW TO JOIN · COUPLE STORIES · ZZUMMI NOTE
ABOUT ZZUMMI · RETURN TO YOUR STORY · NOTE
```

문장형 영어(`We help you find...`)는 쓰지 않는다. 한국어 사이트에 영어 문장이 섞이면 톤이 깨진다.

## 제목 짓기 — 질문형

쩜미노트의 글 제목은 전부 **독자의 속말**을 그대로 옮긴 질문이다.

> 좋은 사람인데, 왜 마음이 움직이지 않을까요?
> 답장이 늦으면, 마음도 멀어진 걸까요?
> 처음 만난 사람에게, 어디까지 솔직해도 될까요?
> 첫 만남의 침묵, 잘 안 맞는다는 뜻일까요?
> 주변은 별로라는데, 저는 한 번 더 만나고 싶어요

정보형 제목("소개팅 후 연락 빈도 가이드")이 아니라 **감정형 질문**. 쉼표로 두 마디로 나눈다.

## 새 카피를 쓸 때 체크

- [ ] 해요체인가
- [ ] 헤드라인이 2~3줄로 끊겨 있는가
- [ ] 숫자·등급 대신 리듬·속도·온도로 말하는가
- [ ] eyebrow 영문 라벨이 명사형 한두 단어인가
- [ ] 불리한 조건을 먼저 말했는가
- [ ] 비교 대상에 실명을 쓰지 않았는가
