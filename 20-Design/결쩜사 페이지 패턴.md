# 결쩜사 페이지 패턴

9개 페이지를 **실제 브라우저에서 렌더링해 캡처**하고 정리했다.
색·타이포 토큰은 [[결쩜사 디자인 시스템]], 문장은 [[결쩜사 카피 톤앤매너]].

> 캡처 절차와 함정(등장 애니메이션 때문에 빈 화면이 찍히는 문제 등)은
> [[레퍼런스 사이트 분석 방법]]에 정리했다.

---

## 1. 페이지 골격 — "시트(sheet)를 쌓는다"

가장 중요한 구조적 발견. 이 사이트는 섹션을 전체 폭으로 깔지 않는다.
**옅은 라벤더 배경 위에 둥근 카드(시트)를 세로로 쌓는다.**

```
┌ 헤더 (흰색 바, 고정)
│
│   ┌───────────────────────────────┐  ← 시트 1 (흰색, radius 20~24px)
│   │  eyebrow / 헤드라인 / 콘텐츠   │
│   └───────────────────────────────┘
│              (간격 24~40px)
│   ┌───────────────────────────────┐  ← 시트 2 (연보라 톤)
│   └───────────────────────────────┘
│   ┌───────────────────────────────┐  ← 시트 3 (흰색)
│   └───────────────────────────────┘
│
└ 푸터 (짙은 자주-검정, 전체 폭)
```

시트 배경은 넷 중 하나로 돌아간다.

| 시트 | 쓰임 |
|---|---|
| 흰색 `#fff` | 기본 정보 블록 |
| 연보라 `#f5f0fc` 계열 | 강조·비교·안내 블록 |
| 크림/금 `#fffdf8` + 금 테두리 | **유료·보상** 블록 (39,000원 카드, 무료 연결권) |
| 짙은 자주 그라디언트 | 쇼케이스·스토리 카드 (SAMPLE PREVIEW, 노트 타일) |

시트 좌우 여백은 `clamp(20px, 4.2vw, 64px)`, 최대 폭 1180px.
우리 앱들은 글 읽는 폭인 **760px** 컨테이너(`.page`)를 쓴다.

> ⚠️ **`.page` 컨테이너가 없으면 시트가 화면 전체 폭으로 퍼진다.**
> 이 패턴의 인상은 "전체 폭 섹션을 쓰지 않는다"에서 나오므로, 컨테이너가 빠지면
> 패턴 자체가 무너진다. 2026-09-03 FitLog에 `.page` 규칙만 없어서 그랬다.
>
> **좁은 창에서는 티가 나지 않는다** — 760px + 여백이라 800px 창에서는 정상처럼
> 보인다. 시트 화면은 **1600px 이상**에서 확인한다.
>
> 함께 필요한 유틸: `.row` `.row--wrap` `.muted` `.btn--sm`.
> 새 앱에 시트 구조를 이식할 때 이 묶음을 통째로 옮긴다.

## 2. 헤더 / 푸터

**헤더** — 흰색 바, 좌측 로고(∞ 마크 + 결쩜사), 우측에 메뉴 + `로그인` + `회원가입`(보라 버튼).
메뉴 왼쪽에 보라 알약 CTA `✦ 프로필 등록하기`가 따로 있다. 모바일에서는 햄버거 하나로 접힌다.

**푸터** — **짙은 자주-검정(`#160b26` 근처) 전체 폭**. 가운데 정렬로
로고 → 사업자 정보 3줄 → `All rights reserved. © 쩜미` → 정책 링크 한 줄.
밝은 페이지 끝에 어두운 블록이 오면서 문서가 닫히는 느낌을 준다.

## 3. 히어로 — 네 가지 변형

페이지 성격에 따라 골라 쓴다.

| 변형 | 쓰는 곳 | 구성 |
|---|---|---|
| **A. 전면 일러스트** | `/` | 밤 정원 일러스트 위 좌측 정렬. 알약 배지 → 3줄 헤드라인(2번째 줄 보라) → 3줄 서브 → 버튼 2개 → `SCROLL ↓` |
| **B. 반반 분할** | `/about` `/events` | 한쪽은 사진, 한쪽은 짙은 자주 패널(또는 연보라). 패널에 eyebrow·헤드라인·서브·버튼 |
| **C. 좌측 정렬 단순** | `/process` | 배경 없이 eyebrow → 헤드라인 1줄 → 서브 1줄. 우상단에 실(結) 장식 |
| **D. 가운데 정렬** | `/pricing` `/notes` `/faq` `/reviews` | eyebrow → 헤드라인 1~2줄 → 서브 1줄. 시트 안에 들어간다 |

**로그인은 별도 변형**이다 → 아래 8번.

## 4. 반복되는 블록 12종

새 페이지는 이 블록들을 조합해서 만든다.

### ① eyebrow + 헤드라인 (모든 블록의 머리)
영문 대문자 라벨(9~11px, `letter-spacing: 2px`, 굵기 800~900) → 국문 헤드라인.
밝은 배경에서는 **보라**, 어두운 배경에서는 **금색(`#ead58c`)**.

### ② 통계 스트립 (`/`)
세로 구분선으로 나눈 4칸. 큰 숫자(보라, 30px+) + 작은 단위 + 아래 라벨.
아래에 각주 한 줄. 신뢰를 숫자로 요약하는 자리.

### ③ 번호 타임라인 (`/process`)
왼쪽에 세로선이 내려오고 `01`~`04` 원형 번호가 걸린다. 마지막 번호만 금색.
각 단계 = 상태 알약 배지 + 굵은 제목 + 설명 + `진행 안내 +` 링크. 단계 사이 얇은 구분선.

### ④ 상태 알약 배지
`지금 바로` `무료` `열람까지 무료` `진행 중` — 아주 작은 라운드 칩.
연보라·민트·금색 톤을 섞어 쓴다. **조건을 제목 옆에 바로 붙여 보여주는 장치.**

### ⑤ 가격 카드 행 (`/pricing`)
카드 3개를 `→` 화살표로 연결. 무료 → 무료 → 유료 순서.
마지막 유료 카드만 **크림 배경 + 금 테두리 + 금색 알약 배지**로 구분한다.

### ⑥ 비교표 (`/pricing`)
좌: 보라 헤더 바 + `✓` 원형 아이콘 행들 / 가운데 `VS` / 우: 흰 헤더 + `✕` 아이콘 행들.
표 아래 오른쪽에 각주 `* 업체·상품별 …`. 경쟁사 실명을 쓰지 않는 방어 장치.

### ⑦ 공식 스트립 (`/events`)
가로로 긴 카드 하나. 좌측 `EVENT FORMULA` 라벨 + `A ＋ B ＝ C`.
결과 칸만 연보라로 강조.

### ⑧ 아이콘 특징 카드 (2×2) (`/`)
흰 카드 + 라운드 사각 아이콘 칩(연보라 배경) + 제목 + 한 줄 설명.

### ⑨ 짙은 쇼케이스 카드 (`/process`)
짙은 자주 그라디언트 카드 안에 **실제 제품 화면 목업**을 넣는다.
금 테두리 알약 eyebrow → 흰 헤드라인 2줄 → 서브 2줄 → 목업.
"사진보다 먼저 이유를 읽는다"는 주장을 UI로 증명하는 방식.

### ⑩ 짙은 타일 카드 그리드 (`/notes`)
3열 그리드. 각 타일은 짙은 자주 그라디언트, 내용은 **아래쪽에 정렬**:
작은 카테고리 라벨 + 우측 `NOTE 05` → 흰 굵은 제목 2줄 → 흐린 요약 2줄.
최신 글 하나만 사진 배경으로 바꿔 변화를 준다.

### ⑪ 스토리 카드 (`/reviews`)
전체 폭 흰 카드. **사진과 글의 좌우 위치를 카드마다 번갈아** 놓는다.
작은 보라 라벨(`결쩜사 1호 커플`) → 큰 이니셜(`JY & MK`) → 직업 조합 → 문단 3~4개.
문단 중 핵심 문장 하나만 **굵게**.

### ⑫ 검색 + 칩 + 아코디언 (`/faq`)
검색 입력(둥근 흰 박스, 우측 돋보기) → 아이콘 붙은 카테고리 칩(활성=보라 채움) →
메타 행(좌: `많이 찾는 질문 6개`, 우: `질문을 누르면 답변이 열려요`) →
아코디언 행(작은 카테고리 배지 + 질문 + `▼`) → `전체 질문 보기 ↓` 전체 폭 버튼 →
도움말 박스(연보라 카드, 제목·설명·버튼 2개).

## 5. 이미지 다루는 법

- 사진은 **항상 둥근 모서리 카드 안에** 들어간다. 전체 폭 사진에도 radius가 붙는다
- 인물 사진에 **자주색 틴트**를 얹어 브랜드 톤에 맞춘다. 흑백 처리도 섞어 쓴다
- 사진 위 캡션은 좌하단, 흰색 굵은 글씨 (`결쩜사는 조건표보다 사람의 리듬을 먼저 봐요.`)
- 얼굴은 가리거나 옆모습·뒷모습을 쓴다

## 6. 장식(ornament)

- **실(結) 곡선** — 얇은 타원 호 2~3개가 겹친 선. 시트 우상단이나 짙은 패널 안에.
  선 굵기 0.8~1px, 투명도 낮은 라일락. 끝에 **금색 점** 하나
- 배경에 아주 옅은 방사형 보라 글로우 2개
- 장식은 **절대 콘텐츠를 가리지 않는다.** 여백에만 놓인다

## 7. CTA

- 주 버튼: 보라 그라디언트(`135deg, #8150E8 → #6830C8`), radius 11px, 흰 글씨 700,
  그림자 `0 10px 24px rgba(104,48,200,.18)`, 화살표 `→` 포함
- 보조 버튼: 흰 배경 + 옅은 테두리, 같은 radius
- 페이지 마지막에는 **가운데 정렬 마무리 CTA**(`준비가 됐나요?` / `결쩜사와 함께 인연을 찾아보세요`)
- 본문 중간에는 텍스트 링크 CTA(`더 궁금한 점이 있으신가요? FAQ 보기 →`)

## 8. 로그인 (`/login`) — 정확한 수치

우리 통합 로그인이 그대로 따르는 구성이다. 실측값:

```
데스크톱: [짙은 스토리 패널 280px] + [흰 폼 카드 420px]  = 한 덩어리
모바일  : 스토리 패널이 위(가로 배너), 폼 카드가 아래
```

| 요소 | 값 |
|---|---|
| 스토리 패널 | `linear-gradient(150deg,#190527,#32104F 65%,#401961)` + 라일락 방사 글로우, radius `24px 0 0 24px`, padding `58px 38px 42px` |
| 폼 카드 | radius `0 24px 24px 0`, padding `48px 42px`, 그림자 `0 24px 65px rgba(37,13,62,.09)` |
| eyebrow | 9px / 900 / `letter-spacing:2px` / `#EAD58C` |
| 탭 | 감싸개 `#F6F1F9` radius 999px padding 3px, 활성 탭 흰색 + `0 4px 15px rgba(38,13,63,.08)`, 12px/800 |
| 폼 제목 | 22px / 700 / `letter-spacing:-0.65px` |
| 폼 서브 | 13px / `#6B5F8A` |
| 라벨 | 12px / 600 / `letter-spacing:0.3px` / `#786B9C` |
| 입력 | radius 10px, `1px solid rgba(72,42,97,.14)`, padding `11px 14px`, 14px |
| 버튼 | 위 CTA와 동일, padding 13px, 15px/700 |

> ⚠️ **폼이 스토리 패널보다 길어지면 패널이 함께 늘어나야 한다.**
> 패널을 `align-self: center` + `min-height: 774px`로 두면, 항목이 많은 가입
> 화면(FitLog은 신체 프로필 3칸이 더 붙는다)에서 패널은 774px에 머물고
> **폼 카드만 아래로 삐져나온다.** 패널만 `align-self: stretch`로 두면 행 높이를
> 따라간다. 폼 카드는 그리드의 `align-items: center`를 그대로 물려받아 제 높이를
> 지키므로, 폼이 짧을 때의 인상(패널이 더 긴 모습)은 바뀌지 않는다.
> 2026-09-03에 실제로 겪었다.

비밀번호 입력 오른쪽에 `보기` 토글이 인라인으로 붙는다.
링크는 카드 하단 가운데 정렬 2줄(`아직 계정이 없으신가요? 회원가입` / `비밀번호를 잊으셨나요?`).

**로그인 화면에도 브랜드 서사를 유지한다** — 폼만 덩그러니 두지 않는다.

## 9. 서체

**Pretendard**(본문 전체) + **Gowun Batang**(감성 구간의 명조).
시스템 폰트 스택으로 대체하면 인상이 완전히 달라진다. 반드시 Pretendard를 불러올 것.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard-dynamic-subset.min.css" />
```

## 10. 새 페이지 만들 때 순서

1. eyebrow(영문 라벨) 정하기 — 블록 성격이 여기서 결정된다
2. 히어로 변형 A~D 중 선택
3. 본문을 **시트 단위로** 나누고, 각 시트에 위 블록 12종 중 하나를 배치
4. 시트 배경을 흰색 / 연보라 / 크림(유료) / 짙은 자주(쇼케이스)로 번갈아
5. 마무리 CTA + 어두운 푸터
6. 장식 곡선은 여백에만, 금색은 강조점에만
