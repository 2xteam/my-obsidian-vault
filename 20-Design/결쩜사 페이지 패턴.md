# 결쩜사 페이지 패턴

9개 페이지를 분석해 공통 골격과 페이지별 변형을 정리했다.
색·타이포는 [[결쩜사 디자인 시스템]], 문장은 [[결쩜사 카피 톤앤매너]].

## 모든 페이지의 공통 골격

```
┌ 상단 알림 배너 (notif-banner, 선택)
├ 헤더
│   로고(결쩜사) · [✦ 프로필 등록하기] 강조 버튼
│   쩜미 소개 · 매칭 방식 · 이용권 · 이벤트 · 고객 후기 · 쩜미노트 · FAQ
│   로그인 · [회원가입]
├ 히어로
│   ① EYEBROW  — 영문 대문자 라벨 (PRICING, ABOUT ZZUMMI …)
│   ② 헤드라인  — 2~3줄, 줄바꿈으로 리듬을 만든 국문
│   ③ 서브카피  — 1~3줄 설명
│   ④ CTA 1~2개 (주 버튼 + 보조 버튼)
├ 본문 섹션 × N   (각 섹션도 eyebrow → 제목 → 내용 구조를 반복)
├ 마무리 CTA
└ 푸터
    사업자 정보 블록 + 정책 링크
```

**eyebrow(영문 대문자 라벨)가 이 사이트의 서명이다.** 모든 주요 블록 위에 붙는다.

| 페이지 | eyebrow |
|---|---|
| `/about` | `ABOUT ZZUMMI` |
| `/process` | `HOW IT WORKS`, `SAMPLE PREVIEW` |
| `/pricing` | `PRICING`, `WHY 결쩜사` |
| `/events` | `FRIEND REFERRAL`, `EVENT FORMULA`, `HOW TO JOIN`, `NOTE` |
| `/reviews` | `COUPLE STORIES` |
| `/notes` | `ZZUMMI NOTE` |
| `/faq` | `FAQ` |
| `/login` | `RETURN TO YOUR STORY` |

## 페이지별 구조

### `/` 홈
히어로(배경 이미지 위 큰 헤드라인 + 배지 2개 + CTA 2개) → 스크롤 유도 표시 →
쩜미노트 배너 → 리포트 섹션. 섹션마다 `.motion-reveal`.

### `/about` 쩜미 소개
서사형. 긴 문단을 760px 폭으로 읽힌다. 중간에 **한 줄 강조문**을 크게 넣어 호흡을 끊는다.
> "결쩜사는 조건표보다 사람의 리듬을 먼저 봐요."

이어서 `SEE / …` 처럼 짧은 영문 라벨 + 국문 설명 카드가 이어진다.

### `/process` 매칭 방식 — **번호 스텝 패턴**
`01 → 02 → 03 → 04` 4단계. 각 스텝은 이렇게 구성된다.

```
[번호]  [상태 배지: "지금 바로 · 무료" / "프로필 확인 후 · 열람까지 무료"]
제목
설명 1~2줄
[진행 안내] 링크
```

아래에 `SAMPLE PREVIEW` — 실제 매칭 카드를 미리 보여준다.
"사진보다 먼저 이유를 읽는다"는 서비스 철학을 UI로 증명하는 구간.

### `/pricing` 이용권 — **가격 카드 + 비교표**
1. 가격 카드 3개: `프로필 등록 0원` → `매칭 확인 0원` → `연락처 교환 39,000원`
   무료 → 무료 → 유료 순서로 배치해 **결제 부담을 마지막에** 보여준다
2. `WHY 결쩜사` 비교표: 결쩜사 ✓ 6개 vs 일부 선납형 서비스 ✕ 6개, 가운데 `VS`
3. 하단 각주: `* 업체·상품별 가격과 운영 방식은 다를 수 있습니다.`
4. 환불 정책 · 목록 5줄
5. `더 궁금한 점이 있으신가요? FAQ 보기 →`

> 비교표에는 경쟁사 실명을 쓰지 않고 "일부 선납형 서비스"로 뭉뚱그린 뒤 각주로 방어한다.

### `/events` 이벤트 — **공식(formula) 패턴**
`EVENT FORMULA` 를 수식처럼 시각화한다.

```
내 회원코드 공유하기  ＋  친구 5명 프로필 등록  ＝  무료 연결권 1회 자동 지급
```

이어서 `HOW TO JOIN` 3단계(01·02·03), 마지막 `NOTE · 이것만 확인해 주세요`에
`*` 로 시작하는 주의사항 3줄. 조건을 숨기지 않고 명시한다.

### `/reviews` 고객 후기 — **커플 스토리**
후기를 별점·평점이 아니라 **이야기**로 쓴다.

```
결쩜사 N호 커플
JY & MK
공기업 직장인 × 디자이너
(3~4문단 서사)
```

이니셜 + 직업 조합만 노출해 신원을 가린다. 숫자 대신 서사로 신뢰를 만드는 방식.

### `/notes` 쩜미노트 — **카테고리 필터 + 아카이브**
상단 필터 칩: `전체 / 관계 심리 / 첫 만남 / 대화와 표현 / 관계의 기준 / 타인의 의견과 내 마음`
목록 아이템:

```
[키워드 라벨: 침묵의 리듬]
NOTE 04
첫 만남의 침묵,
잘 안 맞는다는 뜻일까요?
(한 줄 요약)
```

번호는 최신이 위(NOTE 05 → 01). 제목은 **질문형 2줄**.

### `/faq` FAQ — **검색 + 카테고리 + 아코디언**
- 질문 검색 입력
- 카테고리 칩에 기호를 붙임: `⌂ 전체` `₩ 결제` `↩ 환불` `↔ 진행` `✓ 신뢰` `✎ 프로필`
- `많이 찾는 질문 6개` 우선 노출 + "질문을 누르면 답변이 열려요" 안내
- 각 항목: `[카테고리 배지]` + 질문 + `▼`, 열면 답변 2문단 + 관련 링크

### `/login` 로그인
`← 메인으로` → eyebrow `RETURN TO YOUR STORY` → 감성 문구 →
탭(로그인 / 회원가입) → 폼(이메일 · 비밀번호 + 보기 토글) → 보조 링크 → 푸터.

**로그인 화면에도 브랜드 서사를 유지한다.** 폼만 덩그러니 두지 않는다.

## 새 페이지를 만들 때

1. eyebrow(영문 라벨)를 먼저 정한다 — 페이지 성격이 여기서 결정된다
2. 헤드라인은 **2~3줄, 줄바꿈 위치까지** 설계한다
3. 본문 블록은 아래 중에서 고른다
   - 번호 스텝 (01~04)
   - 가격/기능 카드 3개
   - 비교표 (✓ vs ✕ + 각주)
   - 공식형 (A ＋ B ＝ C)
   - 서사 카드 (이야기)
   - 필터 + 목록
   - 아코디언 Q&A
4. 마무리 CTA + 공통 푸터
5. 각 섹션에 `.motion-reveal`
