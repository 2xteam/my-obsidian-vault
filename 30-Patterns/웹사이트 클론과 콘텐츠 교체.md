# 웹사이트 클론과 콘텐츠 교체

마음에 드는 사이트의 **디자인과 움직임**을 거의 그대로 재현한 뒤, 실제 고객사의 콘텐츠로 갈아 끼우는 절차.
[[Seveny Hair]] 를 이 방법으로 만들었다 (원본: Webflow "Laurence. das Haarlokal").

디자인을 "참고"만 하는 경우는 [[레퍼런스 사이트 분석 방법]] 을 먼저 본다. 이 노트는 그 다음 단계 —
구조·움직임을 수치까지 맞춰 옮기고, 콘텐츠를 교체하고, 배포까지.

## 0. 시작 전에 정할 것 (사용자에게 묻는다)

| 질문 | 기본 답 |
|---|---|
| 원본 폰트가 유료(Adobe Fonts 등)인가 | 무료 대체 폰트로 굵기까지 맞춘다. 키트를 그대로 쓰지 않는다 |
| 원본 이미지·글을 어디까지 쓰나 | **로컬 개발 중 임시로만.** 이미지는 링크만 걸고 레포에 넣지 않는다. 긴 본문은 같은 분량의 임시 문구 |
| 클론할 페이지 범위 | 전체 페이지 (공통 요소를 한 번에 잡는 게 싸다) |
| DB·어드민 | 처음엔 DB 설계 + 시드만. 어드민은 나중 |
| 최종 표기 언어 | 고객 대부분이 한국인이면 결국 한글. 제목만 영어로 남기는 경우가 많다 |

## 1. 원본 분석 — 스크린샷보다 소스가 정확하다

### 파일부터 받는다

```bash
curl -sL https://<site>/ -o index.html            # 페이지마다
curl -sL <css 링크> -o site.css
curl -sL <js 번들들> -o c1.js ...
```

스크립트·srcset 을 지운 정리본을 만들고, **쓰이는 클래스만** CSS 에서 미디어쿼리별로 추출한다
(Webflow 브레이크포인트: 991 / 767 / 479).

### Webflow 라면 움직임은 JS 안에 숫자로 있다 ⭐

`webflow.schunk.*.js` 의 `Webflow.require("ix2").init({...})` 객체를 꺼내 `eval` → JSON 으로 저장.

- `events` — 무엇이 언제 (PAGE_START · PAGE_FINISH · SCROLL_INTO_VIEW · SCROLLING_IN_VIEW · MOUSE_CLICK …).
  target id 는 `<pageId>|<data-w-id>`
- `actionLists` — 그룹별 동작: duration · delay · easing · 이동값 · opacity
- **그룹은 순차 실행** (그룹 0 이 끝나야 그룹 1)
- 연속 스크롤 효과의 `smoothing: 50` → 매 프레임 `current += (target - current) * 0.5`
- `SCROLL_INTO_VIEW` 는 한 번만 재생 (out-of-view 짝 이벤트가 없으면 되돌아가지 않는다)

이 수치를 컴포넌트 주석에 그대로 적어 둔다. 나중에 "느낌이 다르다" 할 때 비교 기준이 된다.

### 프레임 캡처로 눈으로 확인

0.2 / 0.5 / 0.7초 간격으로 연속 캡처해 IX2 수치와 실제 화면이 맞는지 본다 (인트로·메뉴·스크롤).
- Chrome 확장은 **창이 가려지면 멈춘다** → 아래 [[#함정]]
- 창 크기를 못 바꾸면 같은 출처 페이지에 **375 · 820 · 1280px iframe** 을 띄워 미디어쿼리를 확인한다
  (1280px 은 `transform: scale(0.7)` 로 줄여서 한 화면에)

### 하위 페이지는 에이전트에 맡긴다

홈을 직접 분석하는 동안, 정리본 HTML · CSS · ix2.json 을 주고 "페이지별 섹션 구조 / CSS 수치 / 브레이크포인트 /
인터랙션 / CMS 필드"를 마크다운 스펙으로 뽑게 한다. 긴 본문은 단어 수만 적게 한다.

## 2. 구현 — 원본 클래스 구조를 그대로 옮긴다

- **CSS 는 원본 클래스 단위로 옮긴다** (`globals.css` · `subpages.css`). Tailwind 는 `preflight: false` 로 두고 거의 안 쓴다.
  유틸리티로 다시 짜면 수치가 어긋난다
- 폰트는 CSS 변수(`--futura`, `--bodoni`)로 감싸 나중에 한 줄로 바꿀 수 있게
- 움직임은 컴포넌트 3개로 끝난다
  - `Preloader` — 덮개 걷힘 (Web Animations API)
  - `SiteNav` — 메뉴 상태 머신 `closed → mounting → open → closing`, 열기/닫기 타이밍은 CSS transition-delay 로
  - `ScrollEffects` — `[data-reveal]` IntersectionObserver + `[data-float]` rAF 패럴랙스
- `background-attachment: fixed` 는 **쓰지 않는다** → 아래 [[#함정]] 의 FixedBg

## 3. 콘텐츠는 처음부터 데이터로 분리한다

```
src/content/defaults.ts   매장 정보 · 홈
src/content/pages.ts      하위 페이지 · 가격표 · 소개
src/content/photos.ts     사진 주소 한 곳 (R2 이전 시 이 파일만)
src/content/styles.ts     스타일북
src/content/instagram.ts  인스타 게시물 코드
```

- 컴포넌트는 콘텐츠를 **props 로만** 받는다. 문구가 컴포넌트에 박히면 교체 때 놓친다
- `scripts/seed.ts` 가 이 파일들을 그대로 DB 에 넣는다 → 콘텐츠 파일은 다른 모듈을 import 할 때 `.ts` 확장자를 쓴다
  (`allowImportingTsExtensions`, Node `--experimental-strip-types` 로 바로 실행)
- 조회 함수는 **DB → 실패·빈 값이면 기본 콘텐츠**. 실패는 `[db]` 로그로 남긴다 (→ [[Ignite]] 의 교훈)

## 4. 실제 콘텐츠 수집

### 네이버 플레이스 (Chrome 확장은 naver.com 차단 — curl 로)

- 페이지 HTML 의 `window.__APOLLO_STATE__` → 소개 · 메뉴/가격 · 영업시간 · 디자이너 · 링크(인스타·블로그·예약)
- `POST https://api.place.naver.com/graphql` (User-Agent · Referer 필요)
  - `getPhotoViewerItems` cursors `[{id:"biz"}]` → **업체 사진 전부** (페이지 넘김 `lastCursor`)
  - cursor `clip` → 클립 영상 (주소에 hdnts 만료 토큰 → 링크 못 함)
  - `getBeautyStyles` → 스타일 정보 (이름 · 카테고리 · 이미지)
- `ldb-phinf.pstatic.net` 이미지는 외부 링크 허용 (Referer 상관없음)

### 인스타그램

- `instagram.com/p/{code}/media/?size=l` → 항상 최신 CDN 주소로 302
- CDN 은 `cross-origin-resource-policy: same-origin` → **브라우저에서 직접 링크 불가.** 서버 프록시(`/api/ig/[code]`)로 내려준다
- DB 엔 게시물 코드만 저장. 자동 수집(Graph API)은 프로페셔널 계정 + Meta 앱 + 토큰이 필요해서 Seveny 는 **수동 등록**(`npm run ig`)

## 5. 교체할 때 지키는 것

- **원본 흔적 0건 확인** — `grep -r "<원본이름>\|<원본 CDN 도메인>" src` 와 렌더된 HTML 둘 다
- **후기는 지어내지 않는다.** 개별 리뷰 문장을 퍼오지도 않는다 → 리뷰 *키워드 집계* ("원하는 스타일로 잘해줘요" 213명)
- **고객이 올린 사진(방문자 리뷰 사진)은 쓰지 않는다.** 업체가 직접 올린 사진만
- **실명은 꼭 필요한 곳(사업자 정보)에만.** 화면엔 활동명
- 확인 안 된 정보(결제수단 등)는 추정했다고 사용자에게 말한다
- 로고: 원본 로고의 *구조*만 빌려 새로 그린다. 인라인 SVG 면 웹폰트를 그대로 쓰고, 글자를 가르는 띠는 **mask** 로 (흰색 덧칠은 어두운 배경에서 들킨다)

## 6. 한글화

- 원칙을 먼저 정한다: **메뉴·제목 = 영어(디자인), 설명·가격·버튼·이력 = 한글**
- 영문 폰트 뒤에 한글 폰트를 이어 붙여 글자 단위로 대체 —
  `--futura: Jost, "Pretendard Variable", ...` / `--bodoni: "Bodoni Moda", "Noto Serif KR", ...`
- `body { word-break: keep-all }` — 한글 단어 중간 줄바꿈 방지

## 7. SEO (라우트마다)

- `src/content/seo.ts` 에 라우트별 제목 · 설명 · 공유 이미지 문구 · 우선순위
- `routeMetadata(key)` — title · description · canonical · og · twitter 한 번에
- 라우트 폴더마다 `opengraph-image.tsx` / `twitter-image.tsx` → `next/og` 로 **사진 + 로고 + 제목** 1200×630
  - `dynamic = "force-dynamic"` (빌드 때 네트워크 금지)
  - satori 함정: `inset` 단축 속성 모름 → top/left/width/height, `background` 안의 gradient 무시 → `backgroundImage`,
    woff2 못 읽음 → Google Fonts 를 UA 없이 `&text=` 로 필요한 글자만 ttf 로
- `sitemap.ts` · `robots.ts`(`/api/` 막기) · `icon.svg`
- schema.org `HairSalon` JSON-LD (주소 · 좌표 · 영업시간 · sameAs · ReserveAction). **자체 리뷰 평점은 넣지 않는다**
- `metadataBase` = `NEXT_PUBLIC_SITE_URL` → 없으면 `VERCEL_PROJECT_PRODUCTION_URL`

## 함정

- **Chrome 확장 스크린샷이 30초 멈춤** — Chrome 창이 다른 창(Claude 앱)에 완전히 가려지면 Windows 창 가림 감지로
  `document.visibilityState = "hidden"`, rAF 정지. JS 는 실행된다 → `visibilityState` 로 진단.
  Chrome 154 엔 `calculate-native-win-occlusion` 플래그가 없다. **두 창을 나란히(Win+←/→)** 두면 해결 → [[화면 확인의 함정]]
- **모바일에서 고정 배경이 확대돼 보임** — iOS Safari·안드로이드는 `background-attachment: fixed` 를 무시하고
  섹션 *전체 높이*에 cover 한다. PC 를 좁혀 보면 정상이라 놓치기 쉽다.
  → 섹션 안에 `position: fixed; height: 100lvh` 레이어 + 부모 `clip: rect(0,auto,auto,0); clip-path: inset(0)` (FixedBg)
- **next/font/google 빌드 실패** — 캐시 없는 빌드에서 폰트 파일(특히 Noto Serif KR 248개)을 받다가 간헐적으로
  `Cannot read properties of null (reading '1')`. → Google Fonts `<link>` 로 바꿔 빌드에서 네트워크를 뺐다
- **Vercel "No Output Directory named public"** — `public/` 폴더가 없으면 Next.js 로 감지 못 할 수 있다.
  `vercel.json` 에 `"framework": "nextjs"`
- **mongoose 모델 제네릭이 tsc 를 메모리 부족으로 죽인다** — `model<T>()` 대신 타입 인자 없이, 결과에서 타입을 붙인다
- **Webflow 메뉴는 `.click()` 으로 안 열린다** — IX2 는 실제 마우스 이벤트를 본다. 측정은 실제 클릭 + 인터벌 로깅으로
- Bash heredoc 이 특정 내용에서 깨진다 (Windows Git Bash) — 긴 파일은 Write 도구로
