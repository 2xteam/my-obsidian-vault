# 프롬프트 데이터 적재 지침

[[AIKit]] 의 프롬프트 라이브러리를 **어디서 받아 어떻게 넣고 어떻게 보여 주는지.**

프롬프트를 *쓰는* 법은 [[프롬프트 지식베이스]] 에 있다. 여기는 *모으는* 법이다.

```
① 받는다  →  ② 거른다  →  ③ 맞춘다  →  ④ 넣는다  →  ⑤ 보여 준다
```

---

## ⚠️ 먼저 — 전량 적재하지 않는다

`Goku-OpenLab` 은 26,600건이다. **다 넣으면 안 된다.**

- 26,600건을 늘어놓으면 carat.im · yolly.ai 와 똑같은 **범용 프롬프트 갤러리**가 된다.
  [[AIKit]] 의 자리는 거기가 아니다 → [[H AIKit 구축]] "왜 이게 핵심인가"
- 한국어가 없다. `i18n` 은 **en/zh 뿐**이다. 전량 번역은 비용이 감당되지 않는다
- 유사 프롬프트가 매우 많다. 거르지 않으면 목록이 같은 말의 반복이 된다

**목표는 수백 건이다.** 잘 고른 300건이 거르지 않은 26,600건보다 낫다.
큐레이션이 이 파이프라인의 본체고, 나머지는 거기 딸린 배관이다.

---

## ① 받는다 — 출처와 라이선스

| 출처 | 규모 | 라이선스 | 쓰는 곳 |
|---|---|---|---|
| HF `Goku-OpenLab/nano-banana-pro-prompts-datasets` | 26,600+ | **CC BY 4.0** | 기반 라이브러리 |
| HF `poloclub/diffusiondb` | 1,400만 | **CC0** | 보조 (필요할 때만) |
| 자체 저작 | 수십 | 우리 것 | **러닝 등 특화분** |

```python
import pandas as pd
url = "https://huggingface.co/datasets/Goku-OpenLab/nano-banana-pro-prompts-datasets/raw/main/metadata.jsonl"
df = pd.read_json(url, lines=True)   # 133MB
```

- `metadata.jsonl` 만 받는다. **이미지 6GB 는 받지 않는다** (아래 ⑤ 참고)
- 받은 원본은 저장소에 커밋하지 않는다. `.gitignore` 에 넣고 스크립트가 캐시한다

### 쓰지 말 것 — 확인된 사실 (2026-09-17)

| | 왜 |
|---|---|
| GitHub `YouMind-OpenLab/awesome-nano-banana-pro-prompts` | README 는 15,643개라지만 **실제 파일에는 129개**뿐. 나머지는 비공개 CMS. 직접 파싱해 확인 |
| GitHub `sargonelizabeth/Awesome-Nano-Banana-Prompts` | **악성 설치파일 유도.** 프롬프트 리포로 검색에 잡히지만 `.exe`/`.dmg` 를 받게 한다 |
| Lexica API | `lexica.art/api/v1/search` 가 **500**. 죽은 것으로 본다 |
| `ZeroLu/awesome-nanobanana-pro` | NSFW 가 섞여 있다. 거르지 않고 쓰지 말 것 |

### ⚠️ CC BY 4.0 은 표기가 **조건**이다

지켜야 할 것은 셋이다. 하나라도 빠지면 라이선스 위반이다.

1. **출처 표기** — 원저작자와 원 게시물 링크
2. **라이선스 명시** — CC BY 4.0 이라는 사실과 그 링크
3. **변경 여부 표시** — 우리가 프롬프트를 손봤으면 "수정함"을 밝힌다

화면에 이렇게 남긴다.

```
프롬프트 카드 하단 :  출처 <작성자> · <원문 링크> · CC BY 4.0 · 수정함
푸터              :  프롬프트 일부는 Goku-OpenLab/nano-banana-pro-prompts-datasets
                     (CC BY 4.0) 를 바탕으로 합니다
```

⚠️ **CC BY 4.0 은 이 *수집물*에 붙은 것이다.** 개별 프롬프트와 개별 이미지의
원저작권은 각자 따로 있다. 데이터셋 자신도 "copyright belongs to original
creators" 라고 밝힌다. 그래서 아래 ⑤ 에서 **이미지를 자체 호스팅하지 않는다.**

## ② 거른다 — 여기가 본체다

순서대로 걸러 내면 26,600 → 수백이 된다. 각 단계에서 **몇 건이 빠졌는지 찍는다.**

| | 거르는 것 | 방법 |
|---|---|---|
| 1 | 안전하지 않은 것 | `spec.safety_rating` + 금칙어. **의심스러우면 버린다** |
| 2 | 예시 이미지가 없는 것 | `media` 가 비었으면 제외. 결과를 못 보여 주면 카드가 안 선다 |
| 3 | 실명·브랜드·캐릭터가 박힌 것 | 특정 인물명·로고·IP 가 본문에 있으면 제외 |
| 4 | 너무 긴 것 | `charCount` 상한 초과 → 딥링크가 막힌다 |
| 5 | 우리 용도와 먼 것 | 아래 카테고리 화이트리스트 |
| 6 | 중복·유사 | 아래 참고 |
| 7 | 손으로 본다 | **남은 것은 사람이 한 번 본다** |

### 카테고리 화이트리스트

[[AIKit]] 의 첫 메뉴는 **사진을 가진 사람**이 온다. 사진과 무관한 것은 버린다.

```
남긴다   포스터 · 인물/프로필 · 시네마틱 · 소셜 카드 · 사진 보정/스타일 · 타이포
버린다   로고 · 게임 에셋 · 이커머스 상품컷 · 인포그래픽 · UI 목업 · 만화
```

로드맵의 "상황별 프롬프트 카드함" 이 붙을 때 화이트리스트를 넓힌다
→ [[H AIKit 구축]]

### ⚠️ 소재로 고르지 말고 분위기로 고른다

거르는 기준에서 가장 중요한 것이다. **"러닝 사진에 쓸 만한가"로 고르면 안 된다.**

사용자는 소재가 아니라 **느낌**을 고른다 — 시네마틱하게 / 필름 느낌으로 /
흑백 다큐로. 같은 사진이 분위기에 따라 전혀 다른 결과가 된다
→ [[프롬프트 지식베이스]] 분위기 어휘

그래서 큐레이션의 실제 목표는 이렇다.

```
분위기 12개 × 쓸 만한 프롬프트 20~30개  ≈  수백 건
```

- **분위기가 비면 그게 구멍이다.** 전체 건수보다 분위기별 최소 개수를 먼저 채운다
- 한 분위기에 30개가 넘으면 그 안에서 더 고른다. 목록이 길다고 좋지 않다
- 소재가 강하게 박힌 프롬프트(특정 스포츠·직업·행사)는 **일반화할 수 있으면 남기고,
  못 하면 버린다.** 일반화하는 법 → [[프롬프트 지식베이스]]

### 중복 제거

같은 프롬프트가 조금씩 다른 문장으로 여러 번 들어 있다.

1. **정규화 후 해시** — 소문자·공백 정리·문장부호 제거 → 완전 중복 제거
2. **임베딩 유사도** — 코사인 0.92 이상은 한 덩어리로 보고 **대표 하나만** 남긴다.
   대표는 `is_featured` → 이미지 장수 → 최신 순으로 고른다

⚠️ **유사도 임계값은 실측으로 정한다.** 0.92 는 시작값이지 근거 있는 수가 아니다.
너무 낮으면 다른 프롬프트가 뭉개지고, 너무 높으면 중복이 남는다.

### ⑦ 사람이 보는 단계를 빼지 않는다

앞의 여섯은 기계가 한다. 마지막은 사람이다. 검수 화면에서 —

- 프롬프트 본문과 예시 이미지를 나란히 놓고 **버리기 / 남기기 / 승급**
- 승급한 것은 `is_featured` 로 목록 위에 올린다
- 판단 결과를 파일에 남겨 **다시 적재해도 유지되게** 한다 (아래 ④ 멱등)

[[OpenAI Vision 추출 패턴]] 의 "검토 화면을 반드시 거친다" 와 같은 이유다.

## ③ 맞춘다 — 우리 스키마로

### 필드 매핑

| HF `Goku-OpenLab` | `aikit.prompts` | 비고 |
|---|---|---|
| `id` | `sourceId` | 원본 추적용. **비우지 않는다** |
| `slug` | `slug` | 충돌하면 뒤에 숫자 |
| `raw_p` | `body` | 본문 |
| `i18n.en.title` | `title` | |
| `i18n.en.tags` | `tags.raw` | 아래 어휘 매핑 |
| `media[]` | `examples[].url` | **원본 URL 그대로**. 복사하지 않는다 |
| `category` | `category` | 화이트리스트로 변환 |
| `spec.ratio` | `vars.RATIO` 기본값 | |
| `platform` · `sourceLink` | `sourceLink` · `sourceAuthor` | **라이선스 표기에 필수** |
| `is_featured` | `featured` | 참고만. 우리 검수가 덮는다 |
| — | `mood` | **고르는 축.** 자동 분류 후 사람이 확인한다. 아래 |
| — | `license` | `"CC-BY-4.0"` 고정 |
| — | `modified` | 우리가 손봤으면 `true` (표기 의무) |
| — | `charCount` | 계산해서 저장. 매번 세지 않는다 |
| — | `origin` | `dataset` \| `authored` |
| — | `verified` | **실제로 이미지를 만들어 본 것만 `true`.** 처음엔 전부 `false` |
| — | `locale` | `en` \| `ko` |

### 태그 어휘를 A-1 과 맞춘다

**이게 이 문서에서 가장 자주 어긋나는 자리다.**

사진 분석(A-1)이 뱉는 태그와 라이브러리 태그가 같은 말을 써야 매칭이 된다.
어휘가 갈리면 검색은 되는데 **추천이 조용히 빈다.**

```
lib/prompts/vocab.ts   ← 어휘 원본은 한 곳이다
```

A-1 시스템 프롬프트의 값 후보표와 이 파일이 **같은 목록을 본다**
→ [[프롬프트 지식베이스]]

- 매핑되지 않은 원본 태그는 버리지 말고 `tags.raw` 에 남긴다
- 반복해서 쌓이는 원본 태그는 정식 어휘로 **승격**한다
  ([[OpenAI Vision 추출 패턴]] 의 `etc` 승격과 같은 방식)

### `mood` 는 자동 분류 + 사람 확인

원본에 `mood` 가 없다. 우리가 붙인다.

1. 프롬프트 본문과 예시 이미지를 모델에 넣어 **12개 중 하나**를 고르게 한다
   (`temperature: 0` · 후보 목록을 프롬프트에 통째로 넣는다)
2. 확신이 낮으면 `null` 로 두고 **검수 대기**로 보낸다. 억지로 채우지 않는다
3. ⑦ 검수에서 사람이 확인한다. **이건 건너뛰지 않는다** — 분위기가 틀리면
   사용자가 고른 것과 다른 결과가 나오고, 그게 이 앱에서 제일 나쁜 실패다

⚠️ 자동 분류 결과를 그대로 서비스에 내보내지 않는다. `mood` 는 사용자가 **직접
고르는 축**이라 정확도가 곧 제품 품질이다.

### 한국어

`i18n` 에 **ko 가 없다.** 큐레이션이 끝난 뒤에만 번역한다.

- 번역 대상은 `title` 과 한 줄 설명뿐이다. **`body` 는 영문 그대로 둔다** —
  이미지 모델은 영문 프롬프트를 더 잘 따르고, 번역하면 뜻이 흔들린다
- 화면에는 한국어 제목 + 영문 본문. 복사 버튼은 영문 본문을 준다
- 번역도 사람이 한 번 본다. 제목이 어색하면 카드가 안 팔린다

## ④ 넣는다 — 스크립트 규약

**집안 규칙을 따른다: 기본은 검사만, `--write` 를 줘야 쓴다.**
`npm run palette` · `npm run elements` · jangmini `pnpm ingest` 가 모두 그렇다.

```bash
npm run prompts:fetch                  # 내려받아 캐시만
npm run prompts:filter                 # ② 를 돌리고 통계만 출력
npm run prompts:filter -- --write      # 후보 파일 생성
npm run prompts:ingest                 # ③④ 를 돌리되 diff 만 출력
npm run prompts:ingest -- --write      # 실제 적재
```

- 한 단계라도 실패하면 **아무것도 쓰지 않고 멈춘다**
  (`npm run palette` 가 대비 31건 중 하나라도 미달이면 멈추는 것과 같다)
- 각 단계가 몇 건을 들이고 몇 건을 냈는지 찍는다. 조용히 줄어드는 게 제일 무섭다

### 멱등해야 한다

다시 돌려도 같은 결과여야 하고, **사람이 한 판단이 날아가면 안 된다.**

- `sourceId` 를 키로 upsert
- 검수 결과(`verified` · `featured` · 버림 · 한국어 제목)는 **별도 파일**에 두고
  적재 때 덮어씌운다. DB 에만 있으면 재적재 때 사라진다
- 버린 것도 `rejected` 목록으로 남긴다. 안 그러면 다음 적재 때 다시 올라온다

```
content/prompts/curation.json    ← 사람의 판단. 손으로도 고친다
content/prompts/rejected.json    ← 버린 sourceId 와 이유
```

⚠️ 이 둘은 **저장소에 커밋한다.** 사람이 들인 시간이 여기 들어 있다.

## ⑤ 보여 준다

### 예시 이미지 — 자체 호스팅하지 않는다

| | 방법 | 판단 |
|---|---|---|
| A | 원본 URL 핫링크 | **기본.** 저작권이 우리에게 없다 |
| B | 우리 R2 로 복사 | **하지 않는다.** 수집물 라이선스와 개별 이미지 저작권이 다르다 |
| C | 자체 저작분만 R2 | **한다.** 우리가 만든 예시 이미지는 저작권이 분명하다 |

A 의 대가는 **깨질 수 있다는 것**이다. 대응 —

- `onError` 로 프롬프트 전용 카드로 떨어뜨린다. 빈 액자를 보여 주지 않는다
- 깨진 URL 을 기록해 두고 주기적으로 쳐낸다
- `referrerPolicy="no-referrer"` · `loading="lazy"`
- **깨졌다고 R2 로 복사하지 않는다.** 그 순간 B 가 된다

### 카드에 필요한 것 — 스키마는 여기서 역산했다

```
[예시 이미지 1~3장]
제목(ko)            ← 번역본
한 줄 설명(ko)
비율 · 길이 배지     ← spec.ratio · charCount
[복사]  [AI에서 열기]  ← charCount 가 상한을 넘으면 딥링크 버튼을 숨긴다
출처 <작성자> · <링크> · CC BY 4.0 · 수정함   ← 라이선스 조건
```

### 고르는 화면

```
사진 올림  →  [분위기 칩 12개]  →  고른 분위기의 프롬프트 카드들  →  선택
```

- **분위기 칩이 첫 화면이다.** 카테고리나 검색보다 앞에 온다
- A-1 태그로 **어울리는 분위기를 2~3개 먼저 추천**하되, 나머지도 다 보이게 둔다.
  추천은 거들 뿐이고 고르는 것은 사용자다
- 분위기를 고른 뒤에는 **예시 이미지를 크게** 보여 준다. 글보다 그림으로 고른다
- 정렬은 `verified` → `featured` → 최신. **검증된 것을 위로 올린다**
- 고른 프롬프트는 묶음에 `sourcePromptId` 로 남긴다 → [[H AIKit 구축]] Phase 2

### admin

- 끄기 / 켜기 · `featured` 토글 · 한국어 제목 수정
- **신고 받기** — 원저작자가 내려 달라고 할 수 있다. 데이터셋 자신도 그 통로를 둔다.
  끄면 즉시 목록에서 빠져야 한다
- `/admin` 은 앱 DB 를 직접 읽지 않고 `/api/admin/*` 을 부른다 → [[통합 admin]]

## 갱신

원본 데이터셋은 계속 늘어난다.

- **자동 재적재를 걸지 않는다.** 새 건은 ② 를 다시 통과해야 하고 ⑦ 은 사람이 한다
- 분기에 한 번 정도 손으로 돌린다
- 새로 들어온 것만 검수 대기 목록에 쌓는다. 기존 검수 결과는 `curation.json` 이 지킨다

## 확인 안 된 것

- [ ] `metadata.jsonl` 실제 다운로드 — **이 세션 네트워크에서 huggingface.co 가 막혀
      받아 보지 못했다.** 파일 크기·필드는 HF 페이지 기준이다. 첫 검증 항목
- [ ] 필드가 26,600건 전부에 채워져 있는지 (`media` 빈 건 비율 등)
- [ ] `spec.safety_rating` 의 실제 값 분포
- [ ] 유사도 임계값 실측
- [ ] HF 이미지 URL 핫링크가 실제로 되는지 · 속도 · 차단 여부
- [ ] `charCount` 상한 N → [[프롬프트 지식베이스]] "길이 예산"
- [ ] `mood` 자동 분류 정확도 — 사람 판정과 얼마나 맞는지. 낮으면 후보를 줄인다
- [ ] 분위기 12개가 데이터셋에서 **고르게 채워지는지.** 비는 분위기는 직접 저작해야 한다
