# SNS 소개 카드와 게시글

운영자가 **개인적인 이야기**(왜 만들었나)를 주면, AI 가 그 앱의 **인스타그램 카드 묶음**과
**게시글 본문**을 만들어 로컬에 남기는 절차. 2026-09-09 FitLog 에서 처음 했다.

## 입력 — 운영자가 준다

- 앱 이름 (여섯 앱 중 하나)
- 만든 이유가 담긴 **본인 이야기** (날것 그대로. 다듬는 것은 AI 몫)
- 카드 장수·톤에 대한 희망이 있으면 함께. 없으면 8장 기본

## 출력 — 저장소 안 `docs/marketing/` 에

```
<앱>/docs/marketing/instagram-<앱>.html          카드 묶음 (1080×1080, 정방형)
<앱>/docs/marketing/instagram-<앱>-caption.md    게시글 본문 (기본안 · 짧은 안 · 다듬은 기준)
```

- **PNG 는 스크립트로 뽑는다** — 화면 캡처는 흐리다.
  ```
  cd C:/Dev/<앱> && node docs/marketing/export-cards.mjs     → docs/marketing/cards/instagram-<앱>-01.png … (2160×2160)
  ```
  로컬 Chrome(없으면 Edge)을 headless 로 띄워 카드 요소를 2배 해상도로 찍는다. `playwright-core` 는 `klead` 저장소에
  설치된 것을 빌려 쓴다(브라우저를 내려받지 않는다). `SCALE=3` 으로 3240px 도 된다.
  `cards/` 는 `.gitignore` — 언제든 다시 만들 수 있으니 저장소에 두지 않는다.
  스크립트 원본은 `fitlog/docs/marketing/export-cards.mjs`. 다른 앱은 복사해서 파일명만 바꾼다
- 커밋은 운영자 판단. 게시 후 저장소에 남겨 두면 다음 앱의 본보기가 된다

## 카드를 만드는 규칙

1. **문구는 그 앱 소개 페이지(`app/page.tsx`)의 문장을 그대로 쓴다.** 히어로 헤드라인 · HOW IT WORKS 의 STEPS ·
   WHAT YOU GET 의 FEATURES · 마무리 CTA. 새 문장을 지어내지 않는다 — 앱과 카드가 다른 말을 하면 안 된다
2. 카피 톤은 [[결쩜사 카피 톤앤매너]] · 서비스 소개는 [[서비스 카테고리와 카피 원칙]] —
   해요체 · 숫자로 증명하지 않는다 · **다른 서비스를 나열하지 않는다**(계정 공유만 한 줄)
3. 색은 [[먹청 톤 팔레트]] — 청백 `#f7fbfb` · 먹청 `#116271` · 골드 `#ead58c`(어두운 시트 위 강조) ·
   골드 잉크 `#a8842f`(밝은 바탕 글자). 서체는 본문 Pretendard · 헤드라인 Gowun Batang 700 (웹폰트, 인터넷 필요)
4. 시트 구조를 그대로 — 어두운 시트(표지·CTA) / 흰 / 연청록(tint) / 골드를 **번갈아** 쓴다 → [[결쩜사 페이지 패턴]]
5. **앱의 실제 화면 요소를 그림으로 넣는다.** FitLog 는 인바디 삼각 레이더 · 피검사 스포크 차트 · 추이 그래프를
   SVG 로 다시 그렸다(값은 예시). 스크린샷보다 팔레트 안에서 정돈되고, 화면이 바뀌어도 카드가 낡지 않는다
6. 건강·학습처럼 오해가 생길 수 있는 앱은 **하지 않는 것**을 한 장 넣는다 — FitLog 는 "기록이지 진단이 아니에요"
7. 마지막 장은 주소 하나(`<앱>.myjane.co.kr`) + myjane 워드마크. 첫 장은 아이콘 + 히어로 헤드라인

기본 8장 구성 — 표지 → WHY(불편) → HOW IT WORKS → 핵심 기능 그림 2~3장 → 태도/근거 → START.

## 게시글 본문을 다듬는 규칙

- **운영자의 이야기는 운영자의 것이다.** 흐름(시간 순서)과 문장 길이만 다듬고, 사실·감정·숫자는 바꾸지 않는다.
  서비스 카피에는 숫자를 쓰지 않지만 **사람의 기록에 있는 숫자(11kg)는 그대로 둔다**
- 한 문장에 한 가지. 쉼표로 이어진 문장은 둘로 나눈다
- 이야기 → 만든 이유 → 서비스가 하는 일 한두 줄(소개 페이지 문장) → **하지 않는 것** → 공개 문장 → **"프로필의 링크에서 …"** → 해시태그
- **본문에 주소를 쓰지 않는다.** 인스타그램 본문의 링크는 눌리지 않는다. 프로필 링크는 포털의 **`www.myjane.co.kr/link`** 하나로 두고
  (여섯 서비스의 소개 페이지로 가는 링크 모음, `myjane/app/link/page.tsx`), 홍보하는 서비스를 그 페이지 맨 위에 올린다.
  본문에는 "프로필의 링크에서 FitLog 를 열어 보세요" 처럼 적는다
- 첫 줄은 이모지 없이 후킹 한 문장 · 짧은 줄과 빈 줄 · 이모지는 문단 앞뒤에 1~3개 · 마지막은 질문형 CTA
  (2026-09-09 인기 게시글·가이드 조사 — caption.md "참고한 것")
- **해시태그는 5개까지** (2026-09-09 운영자 기준). 고르는 순서 —
  ① 사람들이 실제로 검색하는 큰 태그 셋 (FitLog: #인바디 #피검사 #건강기록)
  ② 게시글의 맥락 하나 (#다이어트기록 처럼 이야기와 맞는 것)
  ③ 서비스 이름 하나 (#FitLog)
  **넣지 않는 것** — #myjane 같은 브랜드 태그(검색 유입이 없다) · #부정맥 같은 질환 태그(진단·처방을 하지 않는 앱에 오해를 부른다) ·
  #건강관리앱 처럼 광고처럼 읽히는 태그. 앱마다 ①은 그 앱의 소재(단어장·오답노트·스티커…)로 바꾼다
- 첫 줄이 잘리는 피드용 **짧은 안**을 함께 둔다
- 다듬은 기준을 caption.md 끝에 적어 다음 사람이 같은 기준으로 고칠 수 있게 한다

## 다섯 앱 모두 있다 (2026-09-09)

| 앱 | 카드 | 문구 | 시각 요소(4장) |
|---|---|---|---|
| FitLog | `fitlog/docs/marketing/instagram-fitlog.html` | 운영자 이야기 포함 (인스타 톤 안) | 삼각 레이더 · 피검사 스포크 · 추이 |
| SnapWord | `SnapWord/docs/marketing/instagram-snapword.html` | 소개 페이지 문장 · **운영자 이야기 자리 비움** | 사진 → 단어장 카드 |
| SnapNote | `SnapNote/docs/marketing/instagram-snapnote.html` | 〃 | 컬러 시험지 → 모노톤 노트 |
| 2hbk | `2hbk/docs/marketing/instagram-2hbk.html` | 〃 | 20칸 스티커판 (13 채움) |
| TypeLog | `typelog/docs/marketing/instagram-typelog.html` | 〃 | 타입 카드 + 도감 |

네 앱은 **한 생성기**로 만들었다 — `myjane/docs/marketing/gen-cards.py` (문구·시각 요소 스펙 + 공통 CSS).
문구를 고칠 땐 HTML 을 직접 고쳐도 되고, 여러 앱을 함께 바꿀 땐 생성기를 고쳐 다시 돌린다(FitLog 는 손으로 만든 원본이라 생성기 밖).
각 저장소의 `export-cards.mjs` 는 범용판이라 폴더의 `instagram-*.html` 을 모두 PNG 로 뽑는다.

카드 8장 구성은 다섯 앱이 같다 — 표지(dark) → WHY(tint) → HOW IT WORKS → 시각 요소 → WHAT YOU GET(tint) → ONE ACCOUNT → 태도/CARE(gold) → START(dark).
네 앱의 게시글은 운영자 이야기가 없어 소개 문장으로만 썼다. caption.md 위에 **이야기가 들어갈 자리와 힌트**를 적어 두었다 —
이야기가 오면 첫 문단으로 올린다. 해시태그는 앱마다 5개(검색 태그 3 + 맥락 1 + 이름 1).

## 첫 사례 — FitLog (2026-09-09)

`C:\Dev\fitlog\docs\marketing\instagram-fitlog.html` (8장) · `instagram-fitlog-caption.md`
운영자의 이야기: 2012년 부정맥 시술 → 14년 뒤 올해 초 악화 → 재진단 → 4월부터 11kg 감량하며 수치를 기록하고
권고를 검색 없이 보려고 만들었다 → 무료 공개. 카드 5장(피검사)은 그날 확정한 스포크 차트를 그대로 그렸다.
