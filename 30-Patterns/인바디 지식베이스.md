# 인바디 지식베이스

`Blood`를 만들고 나서 같은 기준으로 인바디를 다시 세웠다(2026-09-05).
그전에는 조언이 채팅 RAG에만 있었고 **출처가 없었다** — "체중 1kg당 단백질 1.2~1.6g",
"주당 0.5~1% 감량", "활동량 1.2~1.7배". 숫자는 대체로 맞지만 어디서 온 말인지 알 수 없었다.
같은 앱에서 Blood는 근거를 펼쳐 보여주는데 Inbody는 그러지 않으면 어느 쪽을 믿을지 알 수 없다.

구조는 [[피검사 지식베이스]]와 같다 — `lib/evidence.ts`의 등급·`Guidance` 타입을 **둘이 공유**한다.

| | 인바디 | 피검사 |
|---|---|---|
| 항목 정의 | `lib/inbodyKnowledge.ts` (경로 기준) | `lib/bloodCatalog.ts` (코드 기준) |
| 권고 | `lib/inbodyGuidance.ts` | `lib/bloodGuidance.ts` |
| RAG | `lib/inbodyRagChunks.ts` (생성) | `lib/bloodRagChunks.ts` (생성) |

## ⚠️ 인바디에만 있는 함정 — 측정 방법이 곧 기준을 정한다

BIA(인바디)는 DXA와 값이 다르다.

- InBody 770이 전신 근육량을 DXA보다 **+2.28kg**, 사지근육량을 **+1.97kg** 높게 쟀다
- 체지방률은 반대로 낮게 나온다 — 남 **−4.2%p**, 여 **−2.8%p**

그래서 **AWGS 2019 근감소증 기준이 측정 방법마다 다르다.**

| | 남 | 여 |
|---|---|---|
| DXA | 7.0 | **5.4** |
| BIA | 7.0 | **5.7** |

BIA가 근육을 더 높게 재니 판정선도 올려 잡은 것이다.
**인바디 값에 DXA 기준을 갖다 대면 근감소를 놓친다.**

판정에 쓰는 값은 근육량(kg)이 아니라 **SMI(사지근육량 ÷ 키m²)** 다.
그리고 근육량만으로는 근감소증이 아니다 — AWGS는 근력(악력)이나 기능(보행속도)을 함께 본다.
앱은 인바디 값만 아니까 **진단하지 않고** 기준선 아래라는 것까지만 말한다.

## 근거를 찾아 붙인 것

| 내용 | 근거 | 등급 |
|---|---|---|
| 단백질은 체중 1kg당 **약 1.6g**에서 효과가 멈춘다 | 49개 연구·1,863명 메타회귀 (BJSM 2018) | A |
| 근감소증 1차 대응은 저항운동 | AWGS 2019 강한 권고 | A |
| BMI는 근육과 지방을 구분 못 한다 | — | A |
| 내장지방 100cm²는 **일본 기준**, 국내 연구는 갈린다 (남 84~134 · 여 58~91) | 한국인 코호트 | B |
| 세포외수분비 정상 0.360~0.390, 0.400 초과면 진료 | 임상 연구 | B |
| 위상각은 건강 성인 5~7°, 남 평균 7.3 · 여 6.4 | 인구 참고값 | B |
| 위상각을 **올리면 결과가 좋아진다**는 시험은 아직 부족 | — | C |

이전에 근거 없이 말하던 "주당 0.5~1% 감량"은 **B**로 낮췄다 — 특정 숫자를 정한
무작위배정 시험은 없고 관찰에서 나온 실무 권장선이다.

## 화면

피검사와 같은 순서로 맞췄다. **탭을 오가도 같은 앱으로 읽혀야 한다.**

- 항목별 보기를 펼치면 **그 항목이 무엇인지** 먼저 나온다(36/36 전부 설명 있음).
  전에는 위상각·BCM·FFMI가 뭔지 화면 어디에도 없었다
- 레이더 아래 **"이번에 벗어난 항목"** — 표준범위는 이미 저장하고 있었는데 모아주지
  않아서 36개를 다 훑어야 했다
- 판정에 쓴 기준이 결과지에서 온 게 아니면 **밝힌다**(카탈로그 기준 + 출처 링크)

> 조사 함정 — 기준 이름을 문장에 넣으면 "…갈려요)**으로** 표시했어요"가 된다.
> 문장과 기준을 줄로 나눠 조사를 피했다.
