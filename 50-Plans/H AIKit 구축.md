# H AIKit 구축

myjane 일곱 번째 앱 [[AIKit]] 을 0부터 배포까지. [[D jangmini 구축]] 과 같은
성격의 **새 앱 트랙**이지만, jangmini 와 달리 **여섯 앱의 디자인 시스템을 그대로 쓴다.**

앱 자체의 사실(스택·데이터·결정·함정)은 [[AIKit]] 에 둔다.
**이 문서는 순서와 남은 일만** 적는다.

## 무엇을 만드는가

**"AI와 친하게 지내는 앱"** — AI에게 뭐라고 말해야 할지 모르는 사람에게
쓸 문장을 쥐여 주고, **그 결과를 잃어버리지 않게 모아 준다.**

첫 메뉴는 **Prompt Log** 다.

⚠️ **러닝 앱이 아니다.** 사용자는 사진을 올리고 **원하는 분위기**를 고른다 —
시네마틱 / 필름 / 흑백 / 네온 야경 … 소재가 아니라 느낌이 고르는 축이다.
러닝은 파일럿 한 건일 뿐이다 → [[프롬프트 지식베이스]] 분위기 어휘

한 묶음(= 채팅창 하나)이 셋을 함께 갖는다.

```
입력 이미지 여러 장  +  프롬프트  +  생성된 이미지 여러 장
```

흐름은 왕복이다.

```
① 사진 올림        →  ② 어울리는 프롬프트 받음  →  ③ 복사 / AI로 열기
                                                        ↓
⑥ 한 묶음으로 남는다  ←  ⑤ 결과 이미지 올림      ←  ④ 다른 앱에서 생성
```

### 왜 이게 핵심인가 (2026-09-18 사용자 지정)

**이미지 생성은 이 앱이 하지 않는다.** 그런데도 결과 이미지를 보관한다.

ChatGPT·Gemini 에서 만든 이미지는 **대화 기록 속에 묻힌다.** 어떤 프롬프트로
만들었는지, 어떤 원본을 넣었는지가 흩어져서, 두 달 뒤 같은 걸 다시 만들려면
처음부터다. AIKit 은 그 셋을 한 묶음으로 붙들어 둔다.

그래서 이 앱은 **기록하는 앱이다.** [[CalmTouch]] 와 다르다.

프롬프트만 모아 주는 서비스는 이미 여럿이다(promptpocket.app · carat.im · yolly.ai …).
**입력과 결과를 함께 묶는 곳**이 비어 있는 자리다 → [[AIKit]] 참고 항목

## 왜 독립 앱인가 (2026-09-18 사용자 결정)

[[FitLog]] 안의 기능으로 넣는 안, 포털 안에 넣는 안과 함께 검토했고
**독립 앱**으로 정했다. 이유는 범용성이다 — Prompt Log 는 첫 메뉴일 뿐이고,
그 위에 "AI에게 말 거는 법"을 계속 얹을 자리가 필요하다.

⚠️ 랜딩·카피에서 **여섯 앱과 묶어 한 제품처럼 소개하지 않는다.**
AIKit 만 쓰는 사람이 정상이다 → [[서비스 카테고리와 카피 원칙]]

## 이미지 공개 원칙 — 먼저 읽을 것

이 앱의 설계에서 **가장 많이 어긋날 수 있는 자리**다. 한 줄로 요약하면 —

> **R2 객체 URL 을 밖으로 내보내지 않는다. 항상 앱 라우트가 대신 내보낸다.**

| | 누가 본다 | 어떻게 |
|---|---|---|
| 기본 | 본인만 | 앱 라우트가 세션 확인 후 스트리밍 |
| 공유 | 링크를 아는 사람 | 앱 라우트가 **공유 켜짐 + 이 이미지가 선택됨**을 확인 후 스트리밍 |

직링크를 노출하면 **"공유 끄기"가 실제로 먹지 않는다.** 크롤러와 CDN 캐시에
남아서 되돌릴 수 없다. 프록시 라우트면 끄는 즉시 404 가 된다.

### 하지 않기로 한 것 — 딥링크에 이미지 URL 보내기 (2026-09-18)

프롬프트 딥링크에 이미지 URL 을 함께 실어 보내는 안을 검토했고 **접었다.**

1. **모바일에서 안 된다.** 데스크톱 웹 ChatGPT 는 `.jpg`/`.png` 직접 URL 을
   가져오는 경우가 있지만, **모바일 앱은 URL 을 그냥 텍스트로 취급한다.**
   이 앱의 주 사용자가 모바일이라 정작 필요한 곳에서 실패한다.
   (Google AI 요약 기반 — **1차 출처가 아니다. 실측 안 함**)
2. **"이미지를 읽는다"와 "이미지를 참조해 새 이미지를 만든다"는 다른 기능이다.**
   전자가 되더라도 후자가 된다는 근거가 없다
3. **위 공개 원칙과 정면으로 충돌한다.** AI 서버가 가져가려면 그 URL 이 공개여야 한다.
   수명 5~10분짜리 presigned URL 로 줄일 수는 있지만, 그 창 동안은 공개이고
   상대 서비스가 자기 쪽에 복사해 가면 수명이 무의미해진다

대신 **원본 다운로드 버튼**을 준다. 사용자가 그쪽 앱에 직접 올린다.

## Phase 4 — 내보내고 되가져오기

이 앱에서 **가장 깨지기 쉬운 자리**다. 사용자가 앱을 떠났다가 돌아와야 한다.

### 내보내기 — 복사 버튼이 주(主)

프롬프트가 길어서 이게 기본이다. 딥링크는 보조다.
**이미지는 딥링크로 보내지 않는다** — 위 "하지 않기로 한 것" 참고.

### 딥링크 (2026-09-17 조사 · 실기기 미검증)

| 서비스 | URL | 옵션 |
|---|---|---|
| ChatGPT | `https://chatgpt.com/?q=` | `hints=search\|image\|think\|research\|shopping\|study\|canvas` · `temporary-chat=true` |
| Claude | `https://claude.ai/new?q=` | incognito |
| Gemini | `https://gemini.google.com/app?q=` | — |
| Grok | `https://grok.com/?q=` | — |
| Perplexity | `https://www.perplexity.ai/search?q=` | — |
| Claude 데스크톱 | `claude://claude.ai/new?q=` | Anthropic 공식 문서 있음 |

**함정 둘 — 설계에 반영한다.**

1. **전용 앱 스킴은 `claude://` 뿐이다.** 나머지는 전부 https URL 이다.
   모바일에서 앱으로 넘어갈지는 OS 가 정하며 **보장되지 않는다.**
   "앱으로 열기"라고 쓰지 말고 "ChatGPT에서 열기"로 쓴다
2. **길이 제한.** 포스터 프롬프트는 2,000~2,500자이고 URL 인코딩하면 두 배 가까이
   된다. 도구 제공자들도 4,000자를 상한으로 건다.
   → **N자를 넘으면 딥링크 버튼을 숨기고 복사만 남긴다.** N 은 실측으로 정한다

### 되가져오기 — 복귀 설계

- [ ] "결과 올리기" 자리를 묶음 상세에 **비워 둔 채로 보여 준다**
      (돌아왔을 때 어디에 올리는지 찾지 않게)
- [ ] 모바일 — 사진첩에서 여러 장 선택
- [ ] 데스크톱 — 붙여넣기(Ctrl+V)와 드래그 앤 드롭. 생성 직후 복사한 상태가 많다
- [ ] 딥링크로 나갈 때 묶음을 먼저 만들어 두고 복귀 URL 을 남긴다
- [ ] **원본 다운로드 버튼** — 이게 빠지면 흐름이 끊긴다

- [ ] 각 서비스 실기기 검증 (데스크톱 / iOS / Android)
- [ ] **Gemini 가 `?q=` 로 이미지 생성까지 가는지** — 결과물이 이미지인데
      정작 이미지 모델로 넘기는 경로가 제일 불확실하다. **최우선 검증 항목**
- [ ] 길이 상한 N 실측

## Phase 5 — 공유 (2026-09-18 사용자 지정)

프롬프트와 **선택한 이미지**를 링크로 나눈다.

포털에 이미 `/share`(운영자가 고르는 공유 링크 목록)가 있고 [[TypeLog]] 이
`/r/<token>` 을 쓴다. 결이 같다 → [[MyJane]] · [[SNS 소개 카드와 게시글]]

### 만드는 흐름

```
묶음 상세 → [공유 링크 만들기]
  ├ 프롬프트          항상 포함
  ├ 이미지 고르기      썸네일 격자에서 체크. 기본 전부 꺼짐
  └ 동의 체크박스      아래 문구
→ 토큰 생성 → aikit.myjane.co.kr/s/<token>
```

### 동의 문구 — **"간주합니다"를 쓰지 않는다**

개인정보보호법상 동의는 항목·목적·보유기간을 알리고 **명시적으로** 받아야 한다.
"동의한 것으로 간주합니다"로 갈음하기 어렵다. 실제 동의 문장으로 쓴다.

초안 —

> ☐ 선택한 이미지를 공유 링크로 공개하는 데 동의합니다.
>   사진에 다른 사람이 있다면 그 사람의 동의를 받았음을 확인합니다.
>   링크를 아는 사람은 누구나 볼 수 있으며, 공유는 언제든 끌 수 있습니다.

두 번째 문장이 **제3자 문제**를 다룬다. 업로더가 체크박스를 눌러도 사진에 찍힌
친구·행인의 동의를 대신할 수 없다 — 러닝 사진은 단체샷·배경 행인이 특히 흔하다.
완전한 법적 방어는 아니지만, 최소한 고지했다는 기록이 남는다.

- [ ] 체크 없이는 **생성 버튼이 눌리지 않는다**
- [ ] 동의 시각 · **문구 버전** · IP 해시를 기록한다
      (`IP_HASH_SALT` 패턴이 jangmini 에 이미 있다 → [[E 개인정보 보호 보강]])
- [ ] 문구를 고치면 버전을 올린다. 옛 동의가 새 문구를 덮지 않게

### 공유 화면 `/s/<token>`

- [ ] 이미지는 **앱 라우트가 내보낸다.** R2 직링크를 주지 않는다
- [ ] 토큰은 추측 불가능하게 (묶음 id 에서 유도하지 않는다)
- [ ] `robots: noindex` — `/link` · `/share` 와 같다
- [ ] **끄기 = 즉시 404.** 목록과 상세 양쪽에서 끌 수 있게
- [ ] 묶음이나 회원을 지우면 공유도 함께 죽는다
- [ ] 공유 화면에 **입력 사진을 기본 포함하지 않는다** — 체크해야 들어간다
