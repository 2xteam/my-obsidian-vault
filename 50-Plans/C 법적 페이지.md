# C 법적 페이지

개인정보처리방침 · 이용약관 · 쿠키 설정. **포털(myjane)에 두고 여섯 앱 푸터에서 링크**한다.
회원과 세션을 공유하니 방침도 한 곳이어야 한다.

## ⚠️ 초안까지만이다

사용자가 "기본적인 내용으로 초안" 을 승인했다. 그 범위를 지킨다.

- **사실은 정확하게 쓴다** — 아래 실측한 수집 항목·위탁업체를 그대로 옮긴다.
  법적 문서에 실제와 다른 내용을 쓰면 초안이라도 위험하다
- **보관 기간·법적 근거 문구는 확정하지 않는다.** `(확인 필요)` 로 표시해 남긴다
- **법률 검토는 대신할 수 없다.** 공개 전에 사람이 봐야 한다

## 실제로 수집하는 것 — 2026-09-07 코드에서 확인

`users` 컬렉션 (여섯 앱 공용, `models/User.ts`)

| 구분 | 필드 |
|---|---|
| 계정 | `name` `email` `phone` |
| 인증 | `password` `pin` (해시) · `pinResetToken` `passwordResetToken` (+만료) |
| 상태 | `createdAt` `lastLoginAt` `signupFrom` `adminRole` `tokens` |
| FitLog 전용 | `heightCm` `gender` `birthYear` |
| 2hbk 전용 | `userId` `nickname` `profileImage` `emailVerified` `followApprovalRequired` |

**앱 데이터는 각자 DB 에 있다** — `vocab` · `math` · `fit` · `hamhibokka`.
민감한 것은 FitLog 의 `fit` DB 다.

> ⚠️ **건강정보는 민감정보다.** FitLog 는 인바디 수치와 **피검사 결과**를 저장하고
> 결과지 **사진 원본**을 R2 에 보관한다. 방침에 별도 항목으로 분명히 적고,
> 별도 동의를 받아야 하는지 확인이 필요하다 → [[피검사 지식베이스]]

## 쿠키

지금 쓰는 것은 **`snap_user` 하나**다 — 세션 쿠키, `.myjane.co.kr` 도메인 공유.
분석·광고 쿠키는 **없다.**

그래서 쿠키 배너는 필요 없을 가능성이 높다. 필수 쿠키만 쓰면 동의 대상이 아니다.
"쿠키 설정" 페이지는 **무엇을 쓰고 무엇을 안 쓰는지 밝히는 안내**로 만드는 것이
정직하다 — 껐다 켤 게 없는데 토글을 두면 거짓이 된다.

`localStorage` 도 쓴다 — 테마 선택(`fitlog_theme` 등). 쿠키가 아니지만 함께 밝힌다.

## 만들 것

```
myjane/app/legal/privacy/page.tsx     개인정보처리방침
myjane/app/legal/terms/page.tsx       이용약관
myjane/app/legal/cookies/page.tsx     쿠키·로컬 저장소 안내
```

- 시트 구조를 그대로 쓴다(`eyebrow → headline → 본문`) → [[여섯 앱 디자인 시스템]]
- 본문은 긴 글이라 `--content-reading` 폭(760px)을 쓴다
- **여섯 앱 푸터에 링크를 넣는다.** 푸터는 다섯 앱에 복사본이니 함께 고친다
- 가입 화면에 동의 체크박스 + 링크
