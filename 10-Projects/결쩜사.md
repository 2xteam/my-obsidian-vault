# 결쩜사 (kyulzzumsa.co.kr)

매칭(소개팅) 서비스. **우리가 만든 사이트는 아니고, 페이지 작업의 참고 기준**으로 분석했다.

## 왜 참고하나

- 정적 사이트인데 브랜드 완성도가 높다 — 색·서체·모션·카피가 하나로 묶여 있다
- 결제가 있는 서비스에 필요한 표기(사업자정보·환불정책·비교표 각주)를 성실히 갖췄다
- 페이지마다 반복되는 골격이 뚜렷해 **패턴으로 추출하기 좋다**

## 분석 문서

- [[결쩜사 카피 톤앤매너]] — 해요체, 줄바꿈 리듬, 브랜드 어휘

## 기술 구성 (관찰)

- 정적 HTML + `/static/css`, `/static/js` (프레임워크 없음)
- 서체: Pretendard(자체 호스팅) + Gowun Batang(Google Fonts)
- 캐시 무효화: `style.css?v=20260816-static-cache` 형태의 쿼리 버전
- 호스팅: Railway
