# AIKit

myjane 일곱 번째 앱. **AI와 친하게 지내는 앱** — 쓸 문장을 쥐여 주고,
그 결과를 잃어버리지 않게 모아 준다.

착수 순서와 남은 일은 [[H AIKit 구축]] 에 있다. 이 노트는 **앱의 사실**만 갖는다.

## 확정 (2026-09-18 사용자 결정)

|---|---|

## 성격

이미지 생성은 **하지 않는다.** 사진과 **분위기**를 받아 프롬프트를 골라 주고,
사용자는 각자의 AI(ChatGPT · Gemini · Claude …)에서 생성한 뒤 결과를
**되가져와** 앱에 올린다.

Prompt Log 의 한 묶음(= 채팅창 하나)이 셋을 함께 갖는다.

```
입력 이미지 여러 장  +  프롬프트  +  생성된 이미지 여러 장
```

### 왜 보관이 첫 메뉴인가

ChatGPT·Gemini 에서 만든 이미지는 **대화 기록 속에 묻힌다.** 어떤 프롬프트로
만들었는지, 어떤 원본을 넣었는지가 흩어져서 두 달 뒤 같은 걸 다시 만들려면
처음부터다. AIKit 은 그 셋을 한 묶음으로 붙들어 둔다.

그래서 **기록하는 앱이다.** [[CalmTouch]] 와 다르다.

## 이미지 공개 원칙 — 이 앱의 뼈대

> **R2 객체 URL 을 밖으로 내보내지 않는다. 항상 앱 라우트가 대신 내보낸다.**

| | 누가 본다 | 어떻게 |
|---|---|---|
| 기본 | 본인만 | 앱 라우트가 세션 확인 후 스트리밍 |
| 공유 | 링크를 아는 사람 | 앱 라우트가 **공유 켜짐 + 이 이미지가 선택됨**을 확인 후 스트리밍 |

직링크를 노출하면 **"공유 끄기"가 실제로 먹지 않는다.** 크롤러와 CDN 캐시에
남아서 되돌릴 수 없다. 프록시 라우트면 끄는 즉시 404 가 된다.

R2 버킷은 **비공개**다. jangmini 와 **다른 버킷**을 쓴다 — jangmini 는 운영자가
올린 포트폴리오 이미지지만 여기는 사용자 얼굴 사진이다 → [[Cloudflare R2]]

## 딥링크 — 확인된 사실 (2026-09-17)

프롬프트를 각 AI 서비스로 넘기는 URL. **실기기 검증은 아직 안 했다.**

| 서비스 | URL | 옵션 |
|---|---|---|
| ChatGPT | `https://chatgpt.com/?q=` | `hints=search\|image\|think\|research\|shopping\|study\|canvas` · `temporary-chat=true` |
| Claude | `https://claude.ai/new?q=` | incognito |
| Gemini | `https://gemini.google.com/app?q=` | — |
| Grok | `https://grok.com/?q=` | — |
| Perplexity | `https://www.perplexity.ai/search?q=` | — |
| Claude 데스크톱 | `claude://claude.ai/new?q=` | Anthropic 공식 문서 있음 |

- **전용 앱 스킴은 `claude://` 뿐이다.** 나머지는 https URL 이라 모바일에서 앱으로
  넘어갈지는 OS 가 정한다. 화면 문구를 "앱으로 열기"로 쓰면 안 된다
- **URL 길이가 걸린다.** 포스터 프롬프트 2,000~2,500자가 인코딩되면 두 배 가까이 되고,
  도구 제공자들도 4,000자를 상한으로 건다. 긴 프롬프트는 복사만 남긴다
- **이미지는 딥링크로 보내지 않기로 했다** (2026-09-18) — 모바일 앱은 URL 을 텍스트로
  취급하고, "읽기"와 "참조해 생성"은 다른 기능이며, 무엇보다 위 공개 원칙과 충돌한다.
  대신 **원본 다운로드 버튼**을 준다 → [[H AIKit 구축]]
- **Gemini 가 `?q=` 로 이미지 생성까지 가는지는 미확인.** 결과물이 이미지인
  앱인데 그 경로가 제일 불확실하다 — **확인 필요**

### 고르는 축은 소재가 아니라 분위기다

⚠️ **이 앱은 러닝 앱이 아니다.** 파일럿이 러닝 사진이었을 뿐이다.

```
사진을 올린다  →  원하는 분위기를 고른다  →  그 분위기의 프롬프트를 받는다
```

사용자는 "러닝 사진용"을 고르지 않는다. **"시네마틱하게 / 필름 느낌으로 /
흑백 다큐로"** 를 고른다. 같은 사진이 분위기에 따라 전혀 다른 결과가 된다.

그래서 라이브러리도 소재가 아니라 **분위기 12개**로 묶는다. 소재(`activity`)는
보조 필터다 → [[프롬프트 지식베이스]] 분위기 어휘

**소재별로 프롬프트를 쌓지 않는다.** "러닝용 / 등산용 / 카페용"으로 가면 경우의
수가 무한히 늘고, 정작 사용자가 원하는 것은 느낌이다.

**파일럿 1번 — `neon_night` × 포스터** (2026-09-17 작성, 실사용 검증 전)
사진 1 = 인물, 사진 2 = 기록 스크린샷을 받아 4:5 세로 포스터를 만든다.
이 앱에서 처음 만든 프롬프트라 여덟 토막 골격이 여기서 나왔다.
러닝에 묶인 부분은 세 군데뿐이라 변수로 빼면 범용 야간 포스터가 된다.

⚠️ **기록 숫자를 이미지 모델에 맡기면 틀린다.** 앱으로 갈 때는 OCR 로 뽑아
오버레이로 합성하는 쪽이 맞다.

공개 데이터셋에 러닝·마라톤 프롬프트가 사실상 0건인 것은 사실이다(2026-09-17 확인).
다만 그건 **분위기 12개를 채우다 구멍이 나면 직접 저작한다**는 뜻이지,
러닝 프롬프트를 쌓는다는 뜻이 아니다.

프롬프트 전문과 골격, 반복해서 깨지는 다섯 가지, 앱이 OpenAI 에 보낼 시스템
프롬프트는 **[[프롬프트 지식베이스]]** 에 있다. 코드가 그 노트를 원본으로 삼는다.

## 참고 — 이미 있는 서비스 (2026-09-17)

**프롬프트만 모아 주는 곳은 이미 여럿이다.**
promptpocket.app · promptpocket.org · App Store "Ai Prompt Pocket" · carat.im(한국어 1,400+ ·
포스터 90) · yolly.ai · proxima.art · nanobananapro.org

**러닝 사진 생성 쪽도 움직이고 있다.**

- **Morphic** — 사진 한 장 → 러닝 기록 포스터·화보·릴스. 한국 인플루언서 유료광고 집행 중
- **Radiantly** — 얼굴 사진 + 러닝 기록 → AI 러닝 인증 이미지. 역시 한국 광고 집행 중
- **AIReiter** — "사진에서 마라톤 러너 AI 인물 생성기" 템플릿

앞쪽은 **프롬프트 목록**을, 뒤쪽은 **생성**을 판다.
AIKit 은 **분위기를 골라 쓰는 것 + 입력과 결과를 함께 묶는 것**을 판다.

Morphic·Radiantly 는 러닝이라는 소재로 들어갔지만, AIKit 은 소재를 가리지 않는다.
겹치지 않는 자리다.
