# 노트 템플릿 사용법

`Templates` 폴더의 파일을 복사해 새 노트를 시작한다.

옵시디언 앱에서 쓰려면: 설정 → 코어 플러그인 → **템플릿** 활성화 →
템플릿 폴더 위치를 `Templates`로 지정. 이후 `Ctrl+P → 템플릿 삽입`.

| 템플릿 | 언제 |
|---|---|
| `프로젝트 노트` | 새 앱·사이트를 시작할 때 |
| `패턴 노트` | 반복해서 쓸 기법이나 함정을 발견했을 때 |
| `페이지 패턴 노트` | 참고할 사이트를 분석했을 때 |

프로퍼티의 `updated`는 손으로 갱신한다. 자동화가 필요해지면 Templater 플러그인을 검토한다.
