# AI 협업 규칙

Claude Code 등 AI에게 작업을 맡길 때 이 볼트를 어떻게 쓰는지에 대한 약속.

## 볼트 위치

```
저장소: https://github.com/2xteam/my-obsidian-vault
로컬:   C:\Dev\my-obsidian-vault
```

각 프로젝트 저장소의 `CLAUDE.md`가 이 경로를 가리킨다.
AI는 작업 시작 전에 해당 문서를 읽고, 끝나면 바뀐 사실을 볼트에 반영한다.

## 작업 시작 전에 읽을 것

| 작업 성격 | 먼저 읽을 노트 |
|---|---|
| 아무 작업이나 | 해당 프로젝트 노트 (`10-Projects/*.md`) |
| 배포·환경 변수·도메인 | [[Vercel 배포 패턴]] · [[도메인과 DNS]] |
| 이미지 업로드 | [[이미지 업로드 패턴]] |
| 로그인·회원·세션 | [[인증과 세션 공유]] |
| DB 연결 | [[MongoDB Atlas]] |
| 결쩜사 결의 페이지 제작 | [[결쩜사 디자인 시스템]] · [[결쩜사 페이지 패턴]] · [[결쩜사 카피 톤앤매너]] |
| 새 참고 사이트 분석 | [[레퍼런스 사이트 분석 방법]] |

## 작업이 끝나면 볼트를 갱신한다

다음이 바뀌었으면 **해당 노트를 고치고 `updated` 날짜를 올린다.**

- 도메인·DB·버킷·브랜치 같은 사실
- 새로 발견한 함정 (증상 + 원인 + 해결)
- 프로젝트 진행 상황 체크박스
- 새 디자인 토큰이나 컴포넌트 규칙

볼트 수정은 **별도 커밋**으로 남긴다. 코드 커밋과 섞지 않는다.

## 지켜야 할 것

- **비밀값을 볼트에 쓰지 않는다.** 공개 저장소다. 변수 이름까지만 적는다
- 사실과 계획을 구분한다. 계획은 체크박스(`- [ ]`)로 둔다
- 추측을 단정으로 쓰지 않는다. 확인하지 못한 것은 "확인 필요"로 남긴다
- 노트를 새로 만들기 전에 **기존 노트에 들어갈 자리가 있는지** 먼저 본다

## 커밋 메시지

한글로 쓴다. 볼트 커밋은 접두사를 붙인다.

```
docs: FitLog 진행 상황 갱신 — 업로드 화면 완료
docs: Vercel 환경 변수 Secret 함정 추가
```
